# AgentCraft — Python for Agentic AI

A 2-month, career-oriented course that takes students from Python fundamentals to building real, working AI Agents and business automation systems.

**Designed & Taught by:** Yousuf Naveed Khan, Senior Faculty
**Hosted by:** Aptech Gulshan 2, Karachi

## What This Course Covers

- Python fundamentals (variables, data types, control flow, functions, file handling)
- REST APIs, webhooks, and secure credential management
- AI API integration (Google Gemini) with structured output
- Workflow automation with n8n
- AI Agent architecture: tools, memory, and reasoning loops
- Retrieval-Augmented Generation (RAG) with a local vector database
- Human-in-the-loop automation design

By the end of the course, students deliver three portfolio-ready, GitHub-hosted projects:

1. **Smart Lead Intake & AI Triage Pipeline** — a Python automation pipeline combining data processing, an AI classification step, and real-time notifications.
2. **Domain Knowledge Agent** — an AI Agent with RAG-based retrieval, custom tools, and memory.
3. **Capstone: End-to-End Business Automation System** — a full Agentic AI system combining every skill from the course.

## Repository Structure

Each class has its own folder under [`Lectures/`](Lectures/), named `LectureNN-Topic`, containing the code written in that session and a short README covering what was taught, a walkthrough of the code, and common questions.

```
Lectures/

  Lecture02-.../

```

## Prerequisites

- A computer with internet access
- Basic English reading ability
- No prior programming experience required

## Tech Stack

Python 3, VS Code, Git & GitHub, REST APIs, Google Gemini API, n8n, Google Sheets API, Telegram Bot API, Chroma (vector database).
